== NAME

falcodump - Provide interfaces to capture events from Falco plugins

== SYNOPSIS

.Common options
[manarg]
*falcodump*
[ *--help* ]
[ *--version* ]
[ *--plugin-api-version* ]

[ *--extcap-dlts* ]
[ *--extcap-interface*=<interface> ]
[ *--extcap-config* ]
[ *--extcap-capture-filter*=<capture filter> ]
[ *--capture* ]
[ *--fifo*=<path to file or pipe> ]
[ *--log-file*=<path to file> ]
[ *--log-level*=<log level> ]

== DESCRIPTION

*Falcodump* is an extcap tool that provides access to Falco event sources through
Falco plugins. Supported plugins:

1. Cloudtrail (reads Cloudtrail events from an S3 bucket, SQS queue or from a local file or directory, e.g. “k8saudit”)

== OPTIONS

--help::
Print program arguments.

--version::
Print program version.

--plugin-api-version::
Print plugin API version.

--extcap-interfaces::
List available interfaces.

--extcap-interface=<interface>::
Use specified interfaces.

--extcap-dlts::
List DLTs of specified interface.

--extcap-config::
List configuration options of specified interface.

--extcap-capture-filter=<capture filter>::
The capture filter. It corresponds to the value provided via the *tshark -f*
option, and the Capture Filter field next to the interfaces list in the
Stratoshark interface.

--capture::
Start capturing from specified interface and save saved it in place specified by --fifo.

--fifo=<path to file or pipe>::
Save captured packet to file or send it through pipe.

--log-file=<path to file>::
Set a log file to log messages in addition to the console

--log-level=<log level>::
Set the log level

--plugin-source=<source path or URL>::
Capture from the specified location.

== PLUGINS

.CloudTrail plugin options
--cloudtrail-aws-config=<path>::
If non-empty overrides the AWS shared configuration filepath (e.g. ~/.aws/config) and env variables such as AWS_CONFIG_FILE (Default: empty)

--cloudtrail-aws-credentials=<path to file>::
If non-empty overrides the AWS shared credentials filepath (e.g. ~/.aws/credentials) and env variables such as AWS_SHARED_CREDENTIALS_FILE (Default: empty)

--cloudtrail-aws-profile=<AWS profile>::
If non-empty overrides the AWS shared configuration profile (e.g. 'default') and environment variables such as AWS_PROFILE (Default: empty)

--cloudtrail-aws-region=<AWS region>::
If non-empty overrides the AWS region specified in the profile (e.g. 'us-east-1') and environment variables such as AWS_REGION (Default: empty)

--cloudtrail-s3accountlist=<comma separated account IDs>::
If source is an organization CloudTrail S3 bucket download log files for all specified account IDs (Default: no account IDs)

--cloudtrail-s3downloadconcurrency=<number of concurrent downloads>::
Controls the number of background goroutines used to download S3 files (Default: 32)

--cloudtrail-s3interval=<timeframe>::
Download log files over the specified interval (Default: no interval)

--cloudtrail-sqsdelete=<true or false>::
If true then the plugin will delete SQS messages from the queue immediately after receiving them (Default: true)

--cloudtrail-useasync=<true or false>::
If true then async extraction optimization is enabled (Default: true)

--cloudtrail-uses3sns=<true or false>::
If true then the plugin will expect SNS messages to originate from S3 instead of directly from Cloudtrail (Default: false)

== EXAMPLES

An example plugin configuration is available at
https://github.com/falcosecurity/plugin-cloudtrail/blob/main/falco.yaml

.CloudTrail plugin options
[source,console]
--
$ falcodump --extcap-interfaces
interface {value=falcodump-cloudtrail}{display=Falco Cloudtrail plugin}
$ falcodump --extcap-interface=falcodump-cloudtrail --extcap-config
arg {number=0}{call=--cloudtrail-s3downloadconcurrency}{display=Number of concurrent downloads}{type=integer}{default=32}{tooltip=Number of background tasks to download S3 files}{group=Cloudtrail}
arg {number=1}{call=--cloudtrail-s3interval}{display=Timeframe}{type=string}{tooltip=s3invterval}{group=Cloudtrail}
arg {number=2}{call=--cloudstrail-s3accountlist}{display=Account IDs}{type=string}{tooltip=s3accountlist}{group=Cloudtrail}
arg {number=3}{call=--cloudtrail-sqsdelete}{display=Delete SQS messages}{type=boolean}{default=true}{tooltip=sqsdelete}{group=Cloudtrail}
arg {number=4}{call=--cloudtrail-useasync}{display=Use async}{type=boolean}{default=true}{tooltip=useasync}{group=Cloudtrail}
arg {number=5}{call=--cloudtrail-uses3sns}{display=Use S3 SNS}{type=boolean}{default=false}{tooltip=uses3sns}{group=Cloudtrail}
arg {number=6}{call=--cloudtrail-aws-profile}{display=AWS profile}{type=string}{tooltip=aws-profile}{group=Cloudtrail}
arg {number=7}{call=--cloudtrail-aws-region}{display=AWS region}{type=string}{tooltip=aws-region}{group=Cloudtrail}
arg {number=8}{call=--cloudtrail-aws-config}{display=AWS config}{type=string}{tooltip=aws-config}{group=Cloudtrail}
arg {number=9}{call=--cloudtrail-aws-credentials}{display=AWS credentials}{type=string}{tooltip=aws-credentials}{group=Cloudtrail}
--

To capture:

    falcodump --extcap-interface falcodump-cloudtrail --fifo=/tmp/falco.scap --capture --plugin-source yourinitcfg.json --cloudtrail-s3downloadconcurrency 32 --cloudtrail-s3interval 5d-2d --cloudtrail-aws-region eu-west-1

NOTE: To stop capturing CTRL+C/kill/terminate the application.
