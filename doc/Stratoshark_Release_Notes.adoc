This is an experimental release intended to test new features for Stratoshark 1.0.

== What is Stratoshark?

Stratoshark is a system call and log analyzer.
It combines the analysis and filtering features of Wireshark with the capture and data enrichment features of https://falco.org[Falco].
It can be used for troubleshooting, analysis, development and education.

Stratoshark is hosted by the Wireshark Foundation, a nonprofit which promotes protocol and system analysis education.
Stratoshark and the foundation depend on your contributions in order to do their work.
If you or your organization would like to contribute or become a sponsor, please visit https://wiresharkfoundation.org[wiresharkfoundation.org].

The following changes have been made since version 0.10.3:

* The user interface icons have been refreshed, and now scale with the menu:View[] zoom settings.
* Holding down kbd:[↓] and kbd:[↑] will move rapidly through the event list.
* The event bytes pane can show text as UTF-8. Multi-byte characters are
  drawn over the column of their first byte with a “]” over their last byte,
  and hovering over any of those bytes highlights the whole character.
* Coloring rules are now saved as a JSONC file.
  The legacy `colorfilters` file is only read, and converted, when no personal `coloring_rules.jsonc` exists;
  otherwise only the JSONC file is used, so deleted rules no longer reappear from an old legacy file.
  A personal `coloring_rules.jsonc` that cannot be parsed is now reported instead of silently treated as empty.
  Support for the legacy file format will be removed in a future release.
* Support for automatic update notification and updates on Linux distributions supporting PackageKit over D-Bus.

* An issue which prevented loading .scap files generated by Falco or the sysdig CLI utility has been fixed.

The following changes have been made since version 0.9.3:

* Stratoshark can now read https://learn.microsoft.com/en-us/sysinternals/downloads/procmon[Process Monitor] (Procmon) files.

* Welcome Page Redesign
  The welcome page has been redesigned to be more informative and easier to navigate. It now highlights the learning sections better and includes a new sidebar with tips and tricks for using Wireshark effectively. The welcome page is now also more accessible, with improved keyboard navigation and screen reader support.

* Lua Debugger
  A built-in Lua script debugger has been added. It supports breakpoints, single-stepping, variable inspection, expression evaluation, and stack traces.

* Themes
  Stratoshark now uses the same theme system as Wireshark. The colors used throughout the GUI, including graphs, come from a theme instead of individual color preferences; event coloring rules are unchanged. The menu:Appearance[Theme] preferences page lets you pick a theme, choose Light, Dark, or System appearance, and preview the result before applying it. See https://www.wireshark.org/docs/wsug_html/#ChCustPrefsThemeSection[Theme preferences] in the User's Guide for details.
  Besides the default _Stratoshark Default_ theme, a _High Contrast_ theme, two color-blind friendly themes, _Protanopia & Deuteranopia_ and _Tritanopia_, and the themes _Solarized_, _Catppuccin Frappé_, _Catppuccin Macchiato_, _Catppuccin Mocha_, _Tokyo Night_ and _Tokyo Night Storm_ are included. A new _Contrast_ setting (_System_, _Standard_, or _High_) raises the contrast of any theme; _System_ follows the contrast preference of the operating system. The expert information severity icons now differ by shape as well as by color.
  You can add your own themes as `.jsonc` files in the personal themes folder, which is shown in the About dialog's _Folders_ tab and opens from menu:Help[Personal Themes Folder]. See https://www.wireshark.org/docs/wsug_html/#ChCustPersonalThemes[Personal themes] for details.
  If you had customized the event selection, marked, ignored, or Follow Stream colors in the Default profile, Stratoshark converts them once into a personal theme named _Personal (Migrated)_ and selects it, so those colors are kept.

* Theme Designer
  The new menu:View[Internals,Theme Designer...] tool, also reachable from the _Theme Designer..._ button on the menu:Appearance[Theme] preferences page, lets you create your own themes. Copy any theme or start from the default, then edit every color a theme file can set (including the graph colors) and the theme fonts. Colors that are derived from others are shown read-only. Edited colors and fonts are highlighted and can be reverted one by one, and a code view shows the generated JSONC with a diff against the base theme. A mock welcome page and packet list, shown on two tabs, let you try the result in light and dark before you use it. Clicking a part of a sample selects the color that draws it in the Colors tab, and the context menu of a sample lists all colors of that part and saves the sample as an image. Derived colors have a context menu entry that jumps to the color they are computed from. Themes that ship with Stratoshark are read-only and can only be copied. Your own themes are stored with the other personal themes and can be renamed and deleted. Themes can be exported to a `.jsonc` file and imported from one to exchange them with colleagues; imported files are validated and problems are reported.

=== New and Updated Features

Stratoshark can capture system calls locally on Linux and a variety of log sources on Windows, macOS, and Linux.

The following features are either new or have been significantly updated since version 0.9.0:

* The welcome screen's capture-source activity sparklines now keep their history for the whole session.
  Previously the sparklines, and the activity-first ordering of the source list, were reset whenever you
  started or stopped a capture or returned to the welcome screen, so the list re-shuffled each time.
  Now the history persists, the ordering stays stable, and a break in a sparkline marks the interval during
  which a capture was running (statistics are not sampled while capturing).
  When a source is dropping packets, the drops are shown as a separate line.
  wsbuglink:21318[]

* On Linux, Stratoshark can check whether the distribution offers a newer version
  of the package it was installed from. The check uses PackageKit and never
  contacts wireshark.org; the update itself is installed through the desktop's
  software center (e.g. GNOME Software or KDE Discover). Self-compiled builds
  and Flatpak, Snap or AppImage installations are not checked.
  PackageKit is queried over D-Bus, so building with this support only
  requires the Qt DBus module.

* Disabled coloring rules can now be shown in the packet details.
  With the new preference `gui.coloring_rules_include_disabled` (menu:Edit[Preferences > Appearance > Layout],
  "Show disabled coloring rules", off by default) a disabled rule that matches a packet is listed
  under the Frame tree, dimmed and in italics, and can be found with the `frame.coloring_rule.*` fields.
  Disabled rules never color packets. When several rules match, they are listed as a
  "Coloring Rules" subtree with one entry per rule (name, filter string and a Disabled flag);
  the new `frame.coloring_rule.count` field holds the number of listed rules.
  In the Frame tree, the context menu of a coloring rule now offers Disable and Enable,
  which change the rule itself, are saved with the coloring rules and re-dissect the capture.

* The Help menu has a new menu:Help[Discord] entry, which opens the invitation to the Wireshark Discord server.

* The Help menu entries Website and Wiki now show the Stratoshark application icon
  on Linux and Windows (previously they had no icon), and Ask (Q&A) no longer has an icon.

* The monospace font used in the packet list, packet details, packet bytes and other text views
  is now chosen on the new menu:Edit[Preferences > Appearance > Fonts] page, below Theme,
  instead of in the Theme page and the system font dialog.
  The page lists the font families, each drawn in its own typeface, with a filter field,
  a "Show only monospaced fonts" option (on by default), the styles of the family,
  the size (steps of 0.5 points, can be typed) and a sample.
  Strikeout and Underline can be set, and bold or oblique styles are now applied
  (they were stored but ignored before). An italic or underlined font hides the italic and underline markers
  in the packet details, so only their colors mark disabled coloring rules and links then.
  The inline page also fixes the font selection on macOS, where the native font panel
  ignored the monospaced filter and offered no usable size control.
  wsbuglink:21688[]

* A new Distribution dialog (menu:Statistics[Distribution], or the "Distribution" entry in the packet details context menu) counts how often the values of up to four fields occur.
  The fields are entered in a separate _Fields_ line (comma separated, with completion and validation),
  and the _Display filter_ line limits the events that are counted.
  Values sort by their type (numbers, addresses), the new _Resolve values_ option shows value strings,
  a _Show chart_ option draws a bar chart of the most frequent values, and the table updates in place during a live capture.
  Rows can be used as filters from their context menu (including _Copy as Filter_) or sent to the I/O Graph with _Show in I/O Graph_.
  The copied and saved text includes the Count column, `-z distribution,<fields>` opens the dialog, and the dialog has a Help button.

== File Locations

Stratoshark looks in several different locations for preference files, plugins, and other files.
These locations vary from platform to platform.
You can use menu:Help[About Stratoshark,Folders] to find the default locations on your system.
